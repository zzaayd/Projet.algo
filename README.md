# Projet AlgoBox - Binôme

## objectif
Collaborer sur des fichiers `.algo` et suivre les modifications via Git/GitHub.

## Ouvrir le projet
1. Cloner le repo: `git clone https://github.com/<utilisateur>/algobox-collab.git`
2. Ouvrir dans VS Code: `code algobox-collab`
3. Ouvrir les fichiers `.algo` dans AlgoBox pour tester.

## Workflow
- Créer une branche : `git checkout -b feature/nom`
- Pousser : `git push -u origin feature/nom`
- Ouvrir PR et demander review.
- Merger via GitHub et puller sur `main`.
